GBM trial coding - expert validation packet

Thank you for coding these 100 ClinicalTrials.gov records. Your coding, with the other expert's, becomes the reference standard for measuring the accuracy of the study's AI-assisted coding (protocol decision D28, OSF registration osf.io/gn8v5).

What to do

  1. Read the coding manual (01) and the rules addendum (02).
  2. Code every record in 03_records.html (or the matching files in records/), in the order given, in the coding workbook: one row per record in Trials, plus Agents and Biomarkers rows.
  3. Code only from the record text. Do not look the trials up online, and do not discuss them with the other expert until both workbooks are returned.
  4. Steps S1-S4 (study type, start date, phase, age) are computed from structured fields and are not coded by you. Code population (S5), candidate (S6), agents, biomarkers and the trial-level variables for every record, even if a record would fail S1-S4.
  5. Drug origin (approval history) is not coded by you.

The records are the frozen snapshot of 1 November 2026. Some records are not glioblastoma trials; code them as the manual says.
